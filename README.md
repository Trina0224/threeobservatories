# Three Observatories

A web-based 3D simulation of three major space observatories operating in their real orbital environments:

- James Webb Space Telescope (JWST) — Sun–Earth L2 halo orbit
- Nancy Grace Roman Space Telescope — Sun–Earth L2 quasi-halo orbit
- Hubble Space Telescope (HST) — low-Earth orbit

The project combines mission-history playback, physically grounded orbital motion, and an educational visualization layer in one synchronized simulation clock.

## First milestone

Build the simulation with simple markers before detailed spacecraft art:

1. Sun, Earth, Moon, Sun–Earth L1/L2
2. Shared UTC simulation clock and time scaling
3. Hubble propagated in LEO
4. Webb ephemeris/trajectory playback and L2 orbit
5. Roman transfer-to-L2 and L2 orbit
6. Orbit trails and vector overlays
7. Solar-system/L2, Earth-system, and spacecraft-follow camera modes
8. True-scale and educational-scale display modes
